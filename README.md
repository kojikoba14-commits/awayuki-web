# 淡雪 (Awayuki)
▶ **アプリを開く / Open the app**: https://kojikoba14-commits.github.io/awayuki-web/
金継ぎの茶碗をモチーフにした、日々の記録のアプリです。
毎日ひとつの「問い」に答えるだけ。続けるほどに、器の色が白から紅、緋、紫へと移ろいます。

金継ぎや侘び寂びに学びながら作っています。作り手もまだ探究の途中です。

## 使い方

1. 開くと「今日の問い」が出ます。答えを記録してください。
2. 続けるほど、器は「号」を重ねます（全30段階、淡雪〜永愛）。
3. カレンダーの日付をタップすると、その日の誕生花と花言葉が出ます。誕生日や予定も書き込めます。
4. 過去の日付をタップすると、その日の問いと答えを静かに読み返せます。

## こんな仕掛けがあります

- **号**：伝統色名（淡雪・胡粉色・桜色・緋色・江戸紫・牡丹色・永愛 など）で30段階。
- **金継ぎの丸**：続けた日数ぶん、金の線が1日1本ずつ増えます。線が触れ合う所をタップすると「キン」と鳴ります。ポイントとは無関係の、ただの「さわり」です。
- **日が変わると**：カレンダーの一マスが花びらのように捲れて落ち、下に静かに積もります。
- **蔵**：これまでの号の器を眺められます。
- **通知はありません**：アプリを開いた時だけ、静かにお知らせします。
- **日本語 / English**：右上のボタンで切り替えられます（色名は日本語のままです）。

## 記録について

記録はお使いの端末のブラウザに保存されます。ブラウザのデータを消すと記録も消えます。
